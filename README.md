# OfflineSkins

让 Minecraft **离线模式**服务器（以及本地世界）也能显示玩家的正版皮肤与披风。

客户端模组：只需装在你自己客户端上，无需服务端安装同名模组。

## 功能

### 离线服显示皮肤

- 在离线模式服务器里，客户端会根据 **用户名** 查询该名字对应的官方皮肤。
- 只要用户名在 Mojang 上是正版账号名，就会尝试使用其官方皮肤（含披风），不要求你当前是正版登录。
- 离线 UUID、正版登录或开发环境启动，行为一致：以 **用户名** 是否对应正版为准。

### 皮肤来源（按优先级）

1. **Mojang 官方**（可用时）  
   正版用户名优先使用官方皮肤/披风。
2. **本地文件**  
   官方无结果、请求失败，或用户名不是正版时，若本地有对应 png，则使用本地皮肤。
3. **原版**  
   官方与本地都没有时，模组不介入，显示原版默认皮肤。

### 本地自定义皮肤

可在游戏目录下放置与用户名对应的图片（与是否正版无关）：

| 文件                                       | 作用                                     |
|--------------------------------------------|------------------------------------------|
| `cachedImages/skins/<用户名>.png`          | 皮肤                                     |
| `cachedImages/skins/uuid/<uuid无横线>.png` | 按 UUID 指定皮肤（优先于按用户名的文件） |
| `cachedImages/capes/<用户名>.png`          | 披风                                     |
| `cachedImages/capes/uuid/<uuid无横线>.png` | 按 UUID 指定披风                         |

说明：

- 文件名需与游戏内用户名一致（例如用户名为 `Steve` 时，文件名为 `Steve.png`）。
- 使用开发客户端（`runClient`）时，目录相对 `run/` 工作目录。
- 图片需为可被游戏解码的皮肤 PNG（常见为 64×64，亦支持部分高分辨率皮肤）。

### 其它显示

- **Tab 列表**：离线模式下也显示玩家头像（便于对照皮肤）。
- **玩家头颅**：可将头颅渲染替换为对应玩家的模组皮肤（可在配置中关闭）。

## 配置

首次运行会在游戏目录生成 `config/offlineskins.json`：

```json
{
  "useMojang": true,
  "disablePlayerHeads": false
}
```

| 字段                 | 含义                          |
|----------------------|-------------------------------|
| `useMojang`          | 是否启用 Mojang 官方皮肤源    |
| `disablePlayerHeads` | `true` 时不替换玩家头颅的渲染 |

## 运行要求

- Minecraft **Java 版 26.2**
- **Fabric Loader**
- **Fabric API**
- 仅需安装在 **客户端**

## 隐私与网络

- 使用用户名查询 Mojang 公开皮肤数据；本地自定义皮肤只从你的游戏目录读取。
- 不上传你的游戏档案；是否显示他人皮肤取决于该用户名能否在官方查到皮肤，或本地是否有对应文件。
